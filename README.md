# Counter Bot — личный счётчик уроков

Telegram-бот для владельца `1252270301` и дополнительных пользователей из `ALLOWED_USER_IDS`. У каждого отдельный прогресс, цель и напоминания. Node.js 24, встроенный SQLite, без внешних npm-зависимостей. Русские команды и кнопки.

## Что умеет

- Начальный долг **16 тем**, цель **3 темы в день**.
- Кнопка **✅ +1** уменьшает остаток; можно сделать **4/3**, **5/3** и больше.
- Отмена отметки, история за 7 дней, изменение остатка и цели.
- Новые темы автоматически: пн история; вт математика; ср украинский + английский; чт история; пт математика; сб выходной; вс украинский + английский. **8 новых тем в неделю**.
- По умолчанию темы появляются в **18:00 по Киеву**, время меняется командой. В среду и воскресенье обе темы появляются одновременно.
- Прогноз даты учитывает текущий остаток, уже выполненные сегодня темы и все будущие поступления. Это прогноз первого дня с нулём тем после дневного плана и новых поступлений; последующие уроки продолжат приходить.
- Напоминания в **12:00, 18:00, 21:00 по Киеву**, только если есть доступные темы и дневная цель ещё не выполнена. После выполнения цели напоминания прекращаются.
- Время и даты вычисляются с переходом на летнее/зимнее время.
- После перезапуска добавляются все темы, появившиеся за время простоя. Пропущенные дни не считаются выполненными.
- Учёт общий по количеству тем: предметы показывают расписание поступлений; выбирать предмет каждой выполненной темы не требуется.

### Что означает начальный остаток

Первый `/start` создаёт 16 тем **без новых уроков дня запуска**. Если уроки сегодня уже появились, они сразу прибавятся. Если ещё не появились — прибавятся в установленное время.

Например, во вторник до 18:00 будет 16; после 18:00 — 17, если ничего не отмечать. Если твои 16 уже включают сегодняшние уроки, отправь `/setleft 16` после их появления. Эта команда устанавливает остаток **на текущую минуту**, будущие уроки ещё прибавятся.

Вторник, 16 тем до математики, цель 3/день → догнать за **9 дней**, включая вторник. При старте 20.10.2026 прогноз — **28.10.2026**. Четвёртая тема в первый день приближает прогноз до 27.10.

## Создание бота

1. Открой [@BotFather](https://t.me/BotFather) в Telegram.
2. Отправь `/newbot`, выбери название и уникальный username с окончанием `bot`.
3. Сохрани полученный токен в Railway Variables или локальном `.env`. Не публикуй его в GitHub.
4. После запуска сервиса открой своего бота и нажми **Start** / отправь `/start`. До этого бот не начинает учёт и не может присылать личные напоминания.

## Railway: пошаговый запуск

1. В [Railway](https://railway.com/) создай проект: **New Project → Deploy from GitHub repo**.
2. Выбери **maxseryogin/counter-bot** и ветку `main`. Если репозиторий не виден, разреши Railway доступ к нему в GitHub.
3. Railway найдёт `Dockerfile` и соберёт сервис. Build Command и Start Command вручную не нужны.
4. Открой сервис → **Variables** → **Raw Editor** и добавь:

```dotenv
BOT_TOKEN=вставь_токен_от_BotFather
OWNER_ID=1252270301
ALLOWED_USER_IDS=
TZ=Europe/Kyiv
DB_PATH=/data/counter.sqlite
```

5. Добавь к этому сервису **Volume**, установи **Mount Path: `/data`**. В интерфейсе проекта это можно сделать через создание Volume или меню сервиса. SQLite и файлы WAL должны храниться на этом томе. Без Volume данные исчезнут при пересоздании контейнера.
6. В настройках сервиса оставь **1 replica**. Отключи **Serverless / App Sleeping**, если эта опция доступна: фоновому боту нужен постоянно работающий процесс для напоминаний.
7. Примени изменения / запусти **Deploy**. В логах должно появиться: `Counter bot running; private allowlist access only.`
8. Открой своего бота → `/start`. При необходимости сразу измени `/lesson_time 19:00` и `/remind 12:00 18:00 21:00`.
9. Проверь `/status`, нажми **✅ +1**, затем **↩️ Отменить**. После redeploy счётчик должен сохраниться благодаря Volume.

**Домен, публичный порт и HTTP healthcheck не нужны**: бот использует исходящий Telegram long polling. Не запускай локальную копию одновременно с Railway с тем же токеном: Telegram допускает один polling-процесс. Для обновлений достаточно push в подключённую ветку; проверь, что автоматический деплой включён.

Railway использует оплачиваемые ресурсы; доступный план и баланс проверь в своём аккаунте. Сервис должен оставаться включённым, чтобы приходили напоминания.

Официальные инструкции: [GitHub deployment](https://docs.railway.com/guides/github-autodeploys), [Dockerfile](https://docs.railway.com/guides/dockerfiles), [Variables](https://docs.railway.com/variables), [Volumes](https://docs.railway.com/volumes).

## Как добавить человека

В Railway → Variables добавь `ALLOWED_USER_IDS`, например:

```dotenv
OWNER_ID=1252270301
ALLOWED_USER_IDS=987654321,1122334455
```

Замени примерные числа настоящими Telegram ID. `OWNER_ID` тоже всегда имеет доступ — повторять его в списке необязательно. Примени изменения и дождись redeploy. Каждый новый пользователь должен открыть бота и отправить `/start`; у него будут собственные 16 тем и настройки. После этого он может установить фактический остаток командой `/setleft`. Твой существующий прогресс перенесётся автоматически; оставь прежние `OWNER_ID`, `DB_PATH` и Volume.

Чтобы отозвать доступ, удали ID из списка и примени изменения. Напоминания этому человеку прекратятся, его данные сохранятся на случай возвращения. Пустая или отсутствующая переменная оставляет доступ только владельцу.

## Локальный запуск (PowerShell)

Установи Node.js 24 или новее.

```powershell
Set-Location D:\counter_bot
Copy-Item .env.example .env
notepad .env
npm test
npm start
```

В `.env` укажи токен; локально оставь `DB_PATH=./data/counter.sqlite`. npm install не нужен: внешних зависимостей нет. Не копируй локальную базу в Git.

## Команды

- `/start` — начать с 16 тем; повторный вызов сохраняет прогресс.
- `/done` или `+1` — выполнена тема.
- `/undo` — отменить одну сегодняшнюю отметку.
- `/status` — сегодняшний результат, остаток, прогноз.
- `/forecast` — сравнить темп 2, 3, 4, 5 тем/день.
- `/history` — последние 7 дней.
- `/schedule` — расписание.
- `/goal 3` — изменить дневную цель (1–100).
- `/setleft 16` — установить фактический остаток на текущую минуту (0–100000).
- `/add 2` — вручную добавить пропущенные темы.
- `/lesson_time 18:00` — единое время новых уроков.
- `/remind 12:00 18:00 21:00` — до 8 напоминаний в сутки.
- `/pause` и `/resume` — выключить/включить напоминания.
- `/help` — помощь.

При нулевом остатке «+1» не засчитывает ещё не появившиеся будущие темы. В полночь дневной счётчик меняется автоматически; история сохраняется.

Изменение времени уроков не удаляет уже добавленные темы. Напоминания восстанавливаются после краткого простоя только в течение 15 минут от назначенного времени; вчерашние сообщения не отправляются.

## Надёжность и доступ

- Обрабатываются только личные сообщения от `OWNER_ID` и ID из `ALLOWED_USER_IDS`; группы и остальные пользователи игнорируются.
- SQLite атомарно сохраняет прогресс, номер Telegram update и очередь ответов. Повторная доставка update не засчитывает тему дважды.
- Неотправленные ответы переживают перезапуск; сетевые ошибки повторяются. При сбое после успешной отправки до фиксации в базе возможно повторное сообщение, но не повторное списание темы.
- Секретный токен и URL запросов не пишутся в логи.
- Все рабочие данные — SQLite на Volume. Для резервного копирования используй бэкапы Volume; при ручном копировании базы останови сервис и учитывай файлы WAL.
- В тестах проверяются расчёты, расписание, 4/3, отмена, DST, фильтрация владельца, транзакции, перезапуск и повторные updates. Реальный Telegram требует токен, а Railway — запуск в аккаунте.

## Если что-то не работает

- `401` / `Invalid BOT_TOKEN`: проверь токен от BotFather.
- `409` / `Another bot instance`: останови вторую локальную копию или другой Railway-сервис.
- Нет напоминаний: отправь `/start`, проверь `/resume`, часы, дневную цель, остаток и работу сервиса.
- Не сохраняется прогресс: проверь Volume `/data` и `DB_PATH=/data/counter.sqlite`.
